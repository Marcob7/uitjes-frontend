# Municipal logo sources

These files are local copies used by the HomeCitiesShowcaseSection. The interface
renders them as a single burgundy silhouette with CSS masking. For `enschede.svg`,
the opaque source background was removed so the official wordmark can render as a
transparent silhouette.

| --- | --- |
| `apeldoorn.svg` | [Wikimedia Commons: Apeldoorn-gemeente-logo.svg](https://commons.wikimedia.org/wiki/File:Apeldoorn-gemeente-logo.svg), source listed as Gemeente Apeldoorn |
| `amsterdam.svg` | [Wikimedia Commons: Wapen Amsterdam.svg](https://commons.wikimedia.org/wiki/File:Wapen_Amsterdam.svg), public city coat of arms |
| `breda.svg` | [Wikimedia Commons: Breda-gemeente-logo.svg](https://commons.wikimedia.org/wiki/Special:FilePath/Breda-gemeente-logo.svg) |
| `deventer.svg` | [Gemeente Deventer](https://www.deventer.nl/fileadmin/deventer_website/Logos/Logo_Gemeente_Deventer_wit.svg) |
| `delft.svg` | [Wikimedia Commons: Delft-gemeente-logo.svg](https://commons.wikimedia.org/wiki/File:Delft-gemeente-logo.svg), source listed as Gemeente Delft |
| `eindhoven.svg` | [Wikimedia Commons: Eindhoven-gemeente-logo.svg](https://commons.wikimedia.org/wiki/Special:FilePath/Eindhoven-gemeente-logo.svg) |
| `enschede.svg` | [Wikimedia Commons: Enschede-gemeente-logo.svg](https://commons.wikimedia.org/wiki/File:Enschede-gemeente-logo.svg), source listed as enschede.nl |

Municipal wordmarks can remain protected by trademark or house-style rules even
where a Commons file is copyright-free. Amsterdam's municipal logo is deliberately
not used: its public city coat of arms is used instead.
